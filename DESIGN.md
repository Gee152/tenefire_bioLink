# Tenerife Beach - Design Specification

## Overview
High-conversion mobile editorial bio-link for Tenerife Beach, showcasing Brazilian swimwear tailored to the Canary Islands and Spain.

## Colors
- **Turquoise / Sea**: `#0D9488`, `#14B8A6` (Primary brand color, Atlantic ocean vibe)
- **Sand / Dunes**: `#F7F3EA`, `#FDFBF7` (Light mode backgrounds inspired by Canary beaches)
- **Volcano**: `#090D14`, `#0F1622` (Dark mode backgrounds inspired by Teide volcanic rock)
- **Accent**: `#F97316` (Sunset coral), `#F59E0B` (Warm gold)
- **WhatsApp**: `#25D366`

## Typography
- Primary: Plus Jakarta Sans for UI elements and crisp body text.
- Display: Outfit for titles and badges.
- Serif: Playfair Display for editorial accents.

## Layout
- Mobile-first frame (`max-w-md`), centered on desktop with glassmorphism touches and rounded editorial corners (`rounded-[32px]`).
